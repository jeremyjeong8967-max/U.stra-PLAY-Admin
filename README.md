# U.stra PLAY 데모 v1.2.0

관리자: `U.stra PLAY-Admin.html`  
직원용: `U.stra PLAY-Games.html`

## 개발 원칙
- 기존 기능을 임의로 삭제하지 않는다.
- 기존 소스 구조를 최대한 유지한다.
- 기능 변경 전 기존 코드와 영향 범위를 분석한다.
- 변경 후 반드시 테스트한다.
- 오류 발생 시 원인과 해결 방법을 설명한다.

## 작업 규칙
1. 먼저 현재 소스코드를 분석한다.
2. 변경할 파일 목록을 제시한다.

4. 수정 결과와 테스트 결과를 보고한다.

## 문서화
- 주요 기능 변경 시 README를 갱신한다.
- 변경 이력을 기록한다.


프로젝트 폴더의 터미널에서 `node tools/serve.cjs`를 실행하고
<http://127.0.0.1:8765/>를 여세요. 관리자 화면에서 이벤트를 등록하고 직원 링크를 여세요.
종료는 Ctrl+C입니다. 별도 패키지 설치는 필요하지 않습니다.

두 파일은 같은 폴더에 두고 파일명을 유지하세요. 관리자 링크와 미리보기는 직원용 파일을 상대 경로로 엽니다.
두 화면은 같은 주소·브라우저 프로필에서 실행해야 저장소가 공유됩니다.
파일을 직접 여는 `file://` 실행이나 다른 기기에서는 연동이 보장되지 않습니다.
일반 직원 링크는 해당 브라우저의 관리자 저장소에 이벤트가 존재해야 합니다.

수정 사항:

- 직원 링크·미리보기를 이번 직원용 파일에 연결했습니다.
- 삭제 또는 백업 복원으로 제거된 이벤트는 기존 링크로 참여·완료할 수 없습니다.
- 퀴즈 저장 실패 시 최초 제출 판정을 유지하는 재시도 버튼을 제공합니다.
- 직원용 HTML은 CSS, 공통 저장소, 참여 처리, 게임 4종, 초기화 순서로 구분했습니다.

검증: `node --test tests/demo.test.cjs`

테스트는 DOM·저장소를 모의한 로직 검증입니다. 실제 브라우저 화면·모바일 조작 검증은 포함하지 않습니다.
서버 없는 데모의 참여·당첨 처리이며 인증·서버 집계는 제공하지 않습니다.
이벤트 설정은 URL에 포함되므로 실제 개인정보나 실제 경품 운영에 사용하지 마세요.

## 변경 이력

### v1.2.0 — 2026-11-16

- 관리자·직원 화면의 제목, 로고, 참여창, 룰렛 중심, 파비콘을 U.stra PLAY로 통일했습니다.
- [공식 U.STRA HR 소개 페이지](https://www.ustracloud.com/services/intro?servNo=SV0000000133)의
  워드마크를 활용하고 PLAY 표기를 조합했습니다. 참고 색상은 #0354FF, #F6F9FF이며,
  Pretendard 우선 서체와 흰색 카드·넓은 여백을 적용한 데모 디자인입니다.
- 로고는 SVG 데이터로 HTML에 내장해 외부 이미지 요청 없이 표시됩니다.
  Pretendard가 설치되지 않은 환경에서는 Noto Sans KR·맑은 고딕 등 대체 서체를 사용합니다.
- 기존 기본 서비스명 G-PLAY는 읽을 때 새 이름으로 표시하며, 직접 지정한 서비스명과 이벤트·참여 기록은 유지합니다.
- 로직 테스트 14개 및 Edge headless 데스크톱·직원 모바일 화면 검증을 수행했습니다.
